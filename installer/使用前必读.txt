有数 LedgerAI · pre-test 使用前必读
====================================
适用：Windows 10/11 x64；预发布测试版，请先使用测试账套。

1. 安装与启动
安装版运行 YouShuLedgerAI-setup-*.exe；便携版先完整解压 ZIP，
再运行 YouShuLedgerAI.exe，不能只拷走 exe 或在 ZIP 内直接运行。
无需安装 Python 或 Docker。保留后台控制台窗口，关闭它即退出服务。
浏览器通常打开 http://127.0.0.1:8000/app；端口被占用会在8000—8019
内选空闲端口，请以控制台实际地址为准。程序仅绑定本机。
未签名预发布包请只从项目 GitHub Releases 下载并核对 SHA256。

2. 首次使用
空库首次启动创建 admin / admin123456，请在用户管理中立即修改密码。
建账套、核对会计期间和期初余额后，在“模型设置”填写自己的服务商与API Key。
下载包不包含作者的模型密钥、账套、发票或凭证。AI只能生成候选；
确认后为草稿，须由不同审核人审核/过账。税务输出是辅助核对数据。

3. 数据与备份
默认保存在 %LOCALAPPDATA%\有数LedgerAI\data：
ledger.db、attachments、待处理文件、backups、.secret_key、.model_key。
模型密钥加密保存在账套数据库，.model_key是配套解密文件。
“完整备份”ZIP包含账务及解密文件，只作私有备份，严禁作为公开Release附件。
可在程序运行时下载“完整备份”；若直接复制整个data目录，请先关闭程序。
卸载只移除程序；数据目录仍保留。不要在程序目录保存自有文件。

4. 升级
先下载完整备份并保存旧版本，再退出旧程序并安装/解压新版本。
新版本沿用原数据目录，并可能自动迁移数据库。
数据库迁移后不要直接启动旧程序；回退需恢复升级前的完整备份。
便携版建议解压到新文件夹，避免覆盖时残留旧依赖。

5. 多人访问
Windows包为本机版；NAS/局域网部署请参照仓库README的独立说明。
