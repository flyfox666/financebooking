# 有数 LedgerAI · AI 财务记账系统

> 面向小规模纳税人的对话式智能记账系统：把发票、票据、一句话业务描述丢给 AI 助手，
> 生成候选凭证 → 人工确认生成草稿 → 另一人审核 → 过账 → 自动汇总账簿、报表与申报数据。
> **AI 只负责"把业务翻译成凭证"，账目正确性永远不押在模型身上。**

- 文档版本：v2.6（2026-09-07，经营概览与税务核对）· **每次功能更新后须同步本文件**（阶段/功能/亮点章节）
- 详细开发日志与交接细节见 [开发进度与交接.md](开发进度与交接.md)，AI 行为规范见 [AGENTS.md](AGENTS.md)

## 一、项目背景

用户自己经营一家一人有限公司（OPC，上海注册的小规模纳税人），账务此前由家里长辈
（非专业会计）用 Excel 手工记，代账公司又是个黑盒。这个项目用"确定性会计内核 +
AI 智能体外壳"的架构给自家公司做一个自用、轻量、可信赖的记账系统：
家人只管把发票丢进对话框，AI 生成凭证草稿，人核对后落账，报表和申报数据全自动出。

### 2026-09-07 经营概览与税务核对（本轮）

- **本期经营**：本月/本年累计切换，常显收入、成本、毛利、毛利率、期间费用、净利润；展开销售/管理/财务费用、税金及附加、投资收益、营业利润、营业外收支、利润总额和所得税费用。提供收入、净利润较上月的金额变化。
- **资金与往来**：期末账面资金、本月/本年资金变化、经营现金净额，展开现金/银行/其他货币资金及预收预付、其他应收应付。沿用已过账报表口径；金额可下钻到分录并打开原凭证。余额明细包含建账期初说明，尚不支持账龄或逾期判定。
- **独立入口**：左侧新增“经营与资金”，在手机和平板隐藏右栏时仍可查看概览。缺失映射显示待核对，零收入不计算毛利率；提示未过账凭证和计提完整性。
- **税务核对**：2026年日历采用税务总局公布的期限，修正工资薪金所属期及跨年提醒；未知年度标注“待核验”。增值税可切换按月/按季日历视图，此选择仅保存在当前浏览器，不替代税务登记。
- **企业所得税**：用累计利润总额起算，输入截至本期人数/资产季度平均值、行业条件、已预缴金额及预缴调整净额。资料不全时不输出税额；Excel 与页面采用相同输入，并保留待核对状态。当前辅助估算仅核验2026—2027年普通居民公司企业的相关政策，非公司主体或其他年度不输出税额。
- **适用边界**：增值税仍为小规模季度辅助汇总，不能用于按月填报；一般纳税人组合导出已阻止。印花税、财务报表报送等期限须依主管税务机关认定另行核对。此轮未替换小企业会计准则报表，也未增加自动报税。

接口：`GET /api/reports/period-summary` 增加利润构成、资金变化和完整性提示；`GET /api/reports/summary-detail` 按 `book_id/period/key/scope` 分页追溯（`key` 为 `is:net_profit`、`bs:monetary_funds` 等允许项）。`/api/tax/cit` 与 `/api/tax/export` 共用 `employees/assets/industry_eligible/prepaid_prev/adjustment_net/adjustments_confirmed`；`/api/tax/calendar` 与 `/api/tax/reminders` 支持账套校验和 `vat_frequency`。

政策依据：[2026年申报纳税期限](https://fgk.chinatax.gov.cn/zcfgk/c102424/c5245729/content.html)、[企业所得税预缴申报表](https://12366.chinatax.gov.cn/bzds/059/059.html)、[小型微利企业所得税政策](https://fgk.chinatax.gov.cn/zcfgk/c100024/c5236888/content.html)。会计准则与纳税人身份须分开判断；[财会〔2026〕11号](https://ah.mof.gov.cn/tongzhitonggao/202608/t20260810_3995173.htm)的修订不意味着增值税小规模纳税人一律立即换表。本项目本轮继续使用现有小企业会计准则模板，后续按适用准则和生效日期做版本管理。

复测命令：`docker compose -f docker-compose.test.yml --profile tests run --rm tests`；最终证据、剩余产品工作见交接文档。当前税务输出仍为申报辅助结果，不应将软件测试通过等同于税务口径已完成专业审定。

│  ├── ledger/ai/agent ── AI 智能体（system prompt + 工具白名单 + 硬护栏）             │

│         │ SQLAlchemy 2.0                                                          │
│  SQLite /data/ledger.db（单文件，卷挂载宿主 data/，每日 3:00 自动备份）               │
└──────────────────────────────────────────────────────────────────────────────────┘

**核心架构决策：AI 无任何过账/审核权限**——智能体只能产出"候选凭证"，
工具白名单仅查询类 + ask_user；落账必须由人在凭证卡片上点击确认，经借贷平衡、
科目合法性、重复检测等硬校验后进入凭证流程（草稿→审核→过账）。

## 四、已实现功能

### 核心账务
- 凭证全生命周期：草稿 → 提交审核 → 审核通过/驳回 → 过账 → 反过账，角色权限（制单/审核/管理员岗位分离）
- 小企业会计准则 66 科目、明细科目管理、账套管理、期末结转
- **多账套管理与切换**：顶栏账套下拉切换（期间/对话历史/主数据按账套隔离防串账）；
  新建账套自动预置科目/模板/税务参数并引导录期初；user_book 成员表（数据层多租户地基，
  admin 全可见、成员按授权可见，账套级访问校验 require_book_access）
- **账套成员管理**：用户管理页「账套授权」弹窗（勾选账套+账套内角色），4 个成员端点；
  **全部业务路由已挂账套访问校验**（凭证/报表/发票/附件/往来/税务/AI/结账，
  非成员跨账套访问一律 403）；删用户级联清理授权；最低可管性守护（账套不得无管理员）；
  全局角色=岗位（制审分离）× 账套成员=门禁（进哪些公司的账）
- 报表：科目余额表、资产负债表、利润表、现金流量表、总账/明细账、Excel 导出
- 辅助核算：四类往来单位（客户/供应商/员工/其他），科目挂辅助类型，凭证往来强校验

### 报表引擎
- **模板驱动取数**：报表行 = ReportTemplate 取数公式（科目+符号），支持在线编辑映射、一键恢复默认
- **表结法**：资产负债表"未分配利润" = 3103+3104+全部损益科目，期中报表恒满足
  资产 = 负债 + 所有者权益（对齐金蝶/用友口径）
- **映射体检页**：恒等式实时校验、未映射科目清单（有余额标红）、公式脏引用检测
- **现金流量行级标注**：分录现金行可指定 14 个流量项目（一张凭证拆多个流量项），
  未标注部分按"对方最大行科目"兜底推断，报表永不缺数
- **余额表未过账口径切换**：三档切换——仅已过账 / 含未过账（待审+已审）/ 含草稿；
  未过账金额走独立列（不计入已过账三栏、不破坏恒等式），含草稿档带预警提示
- **账务勾稽关系校验**（余额表 & 映射体检打通）：方向/余额异常（资产贷方、负债借方、货币资金赤字）、
  未分配利润↔净利润、货币资金↔现金流、跨期衔接四类校验，徽章式逐项 ✅/❌ + 异常明细展开

### AI 智能记账（主视图对话助手）
- 对话式记账：上传发票 PDF / 输入业务描述 → 解析 → 生成候选凭证卡片 → 人工确认落账
- 助手为标准主视图（与凭证/报表同交互模型），对话历史跨视图切换保持，首次进入有引导
- **支付截图直接记账**：微信/支付宝/银行支付记录自动识别（渠道/收付方向/对方/金额/时间/事项），
  AI 按用途生成凭证，零钱走 1012 其他货币资金、银行卡走 1002，分不清会主动问
- **多票据同图拆分**：一张照片拍两张发票、或发票+支付记录混拍，自动拆成多条候选逐张生成凭证
- **合同/报价单（docx）直接理解**：证据类文件提取全文（段落+表格）交 AI 理解生成凭证，
  卡片标注「建议附发票」提醒取得扣除凭据；超长自动截断，老版 .doc 引导另存
- 发票全量底册：金税 Excel 批量导入 + 单张 PDF 落账自动补录台账，销项/进项方向判定，
  发票↔凭证双向关联，发票行一键"AI记账"
- 凭证电子原件：落账自动挂附件（SHA256 校验），附件浮层管理（批量上传/删除，过账锁定）
- 价税规则按纳税人性质动态注入（小规模进项严禁拆税 / 一般纳税人双向分离）
- **AI 记账偏好（账套级）**：侧栏「🧩 AI 偏好」配置行业标签（软件/AI/电商/咨询/贸易/餐饮 6 包，可多选组合——AI 包含算力与大模型费用分摊、研发资本化确认、技术开发合同免税备案提醒）
  + 业务描述自由补充 + **自定义模板**（所见即所得编辑器，按标签自动生成后可直接修改，
  不选标签直接编写即纯自定义，手动修改后标签联动不覆盖、可一键重新生成）→ 注入智能体提示词
  理解业务背景（收入识别/科目倾向/摘要风格）；外包护栏文本永不凌驾核心记账规则，
  自定义模板为空回退标签合成，未配置零行为变化——多公司开放即用的模板化方案
- 往来单位"查找-确认-新建"流程，购方与账套公司不匹配时主动警告

## 五、设计亮点与创新

1. **三层护栏模式**（核心范式）：AI 生成账务数据必过三道关——
   ① Prompt 软约束（注入公司信息/日期/价税规则）→ ② 人工确认（卡片 + ask_user 追问）→
   ③ 代码硬兜底（重复拦截、往来 ID 净化、现金流量自动标注、价税规则强制）。
   模型不听话也污染不了账本。

2. **查重双保险（实质性重复导向）**：发票号精确命中已入账发票是金标准；金额通道收紧为
   **同日 + 同金额 + 科目类别一致 + 往来对象不冲突**（同一单据二次录入的特征）才提示——
   仅金额相同不拦（重复金额是正常业务），代码层 `_hard_check_duplicate` 同口径强制兜底。

3. **报表与 AI 解耦**：AI 只管把凭证做对，报表永远从已过账凭证经模板公式聚合——
   模型可换、公式可改，互不影响。

4. **表结法恒等式**：未分配利润公式吸收全部损益科目净额，任何时刻打开资产负债表都平衡，
   不依赖期末是否已结转。

5. **单文件零依赖前端**：约 2000 行原生 HTML/CSS/JS 承载全部交互，无构建链，
   在低配 NAS/家庭服务器上秒开。

## 六、使用指南（日常操作）

### 日常做账闭环
1. **录账**：AI 助手视图上传发票 PDF/图片、支付截图、合同 docx，或直接一句话描述业务 →
   AI 生成候选凭证（缺信息会追问；疑似重复、购方与账套不符会警告确认）
2. **确认落账**：核对凭证卡片（科目/金额/日期/往来/现金流量）→ 点「确认入账」生成草稿
3. **审核过账**：审核岗在凭证列表「审核通过 → 过账」（岗位分离，AI 无任何过账权限）
4. **看数**：科目余额表（三档未过账口径切换 + 顶部勾稽徽章）→ 报表模块三大表
5. **月末**：期末结转生成结转凭证 → 审核过账 → 结账（快照冻结，跨期衔接据此校验）

### 谁可以切换账套（心智模型）
**账号是登录凭证（决定能干什么活），账套成员是门禁卡（决定能进哪些公司的账）。**
admin 可切换所有账套（天然全权限）；制单/审核账号只能切换到被授权的账套，
未授权的账套连下拉选项都不会出现。授权入口：用户管理 → 账套授权。

### 角色与权限
- **admin**：全部权限 + 新建账套 + AI 偏好 / 模型设置 / 报表映射模板编辑，天然可见所有账套
- **bookkeeper（制单）**：录凭证、提交审核（账套访问按成员授权）
